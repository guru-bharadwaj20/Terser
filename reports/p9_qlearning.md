## C9.1 Tabular convergence

Most settled learner (alpha=visits, gamma=0.99, decay=0.9995, eps_min=0.0): max |dQ| over the last 1,000 episodes = **1.64e-01** (target < 1e-3: **fail**).

**Why C9.1 fails.** The state `(filler, constraint, length buckets, category, ops applied)` lumps
many different prompts together. After the same action in the same state, the STOP reward
depends on *which* prompt was drawn, swinging between about +40 (savings) and about -100 (gate
says degraded), so the environment is stochastic at the table level. With a constant alpha the
Q-values track a moving average of these samples and never settle (max |dQ| ≈ alpha x reward
spread: 2.2-22 with exploration on, about 1 once epsilon anneals to 0). The `visits` learners use
the Robbins-Monro step alpha = 1 / N(s, a), which removes that floor: with epsilon annealed to 0
max |dQ| drops to 0.16-0.38, the most settled tables in the sweep. It is still far from 1e-3
because a 1 / N update moves Q by (reward spread) / N, and the rarest state-action pairs still
updated in the last 1,000 episodes have only hundreds of visits; reaching 1e-3 against a spread
of about 140 needs on the order of 10^5 visits per pair, beyond the 30,000-episode budget. A
richer state (less aliasing, smaller spread) or a far longer run would be needed. The
highest-return learners are the `visits` ones with epsilon floored at 0.05, which keep exploring
and therefore keep moving (max |dQ| about 20).
