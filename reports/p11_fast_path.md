# CPU fast path exported to ONNX (row 11.3.2)

Generated by `python -m terser.phase11.train_fast_path`. No GPU and no language model on this path: features are the serving feature code (`terser.features.shared`, `terser.serving.fast_models.span_matrix`), inference is ONNX Runtime `CPUExecutionProvider`.

| component | model | training data | grouped CV | ONNX vs sklearn max dP | file |
|---|---|---|---|---|---|
| gate | GradientBoosting (200 x depth 3) on 30 shared features | 14,732 labelled train pairs | AUC 0.760 | 1.0e-07 | `models/fast/gate.onnx` |
| span tagger | DecisionTree (depth 10) on 10 cheap word features | 129,380 train words | droppable macro-F1 0.631 | 2.9e-08 | `models/fast/tagger.onnx` |

Single-request CPU latency (tagger rewrite + gate, 300 train prompts, warm): p50 **1.1 ms**, p95 **7.3 ms** (measured with the original prompt's features cached and no explicit warm-up, so an underestimate; the timing loop now extracts them per request after warm-up calls). Median savings of the fast-path rewrite before the gate: 28.6%.

The gate is weaker than the Phase 5 LightGBM (AUC 0.778) because it sees only surface features (no GPT-2 surprisal, no embeddings); that is the price of a GPU-free, millisecond path. The quality path (11.3.3) carries the generative rewriter.

## Gate operating point (row 3.2.3)

Scores: the grouped 5-fold out-of-fold `P(degraded)` behind the AUC above (same 30 features, same model spec, groups = source prompt, seed 0; 14,732 pairs, degraded = positive). The service rejects a rewrite when `P(degraded) > gate_threshold` and returns the original prompt, so sensitivity is the share of degraded rewrites rejected and specificity the share of preserved rewrites passed. Rule: maximise specificity subject to sensitivity >= 0.95 (`terser.eval.threshold.choose_threshold`, which flags `score >= 0.264565`), written as the shortest decimal that flags the same pairs under the service's strict `>` (`service_threshold`).

| threshold | value | sensitivity | specificity | rewrites passed | degraded among passed |
|---|---:|---:|---:|---:|---:|
| old default | 0.5 | 0.646 | 0.708 | 55.6% | 27.5% |
| **row 3.2.3 rule (deployed)** | 0.264564 | 0.950 | 0.380 | 23.7% | 9.0% |

Overall degraded share: 43.1%. Average precision (pooled OOF): 0.680. At 0.5 the gate passes 35.4% of degraded rewrites, so it does not meet the 0.95 sensitivity floor. The chosen value is set as `gate_threshold: 0.264564` in `configs/serving/fast_onnx.yaml`.
